# persian-kit

Installs the whole Persian kit in one step: persian-fonts (the Persian font), persian-rtl (right-to-left layout and the
`/persian-patch` command for Claude Desktop) and persian-writing (Claude writes correct Persian). It contains no code of
its own. The plugin is called persian-kit because plugin names that start with claude- are reserved. Install it with
`claude plugin install persian-kit@claude-persian-kit`.

Part of [claude-persian-kit](../../README.en.md) ([فارسی](../../README.md)). MIT.

Install:

```
/plugin install persian-kit --marketplace hosseinhabibi2004/claude-persian-kit
```
