# persian-fonts

Chooses the Persian font for Claude Desktop: Vazirmatn, which is bundled (SIL Open Font License, see `fonts/OFL.txt`),
or any font installed on your computer. The font is used for Arabic-script characters only; code, monospace and Latin
text keep their own font. `/persian-font` shows the choice and `/persian-font "B Nazanin"` saves another one. To apply
it inside Claude Desktop, run `/persian-patch font "B Nazanin"` from the persian-rtl plugin.

Part of [claude-persian-kit](../../README.en.md) ([فارسی](../../README.md)). MIT.
